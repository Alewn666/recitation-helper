## 第 2 轮（2026-10-17）：去掉学生起名/登录步骤 → 匿名编号

**用户要求**：「把那个学生登录的功能去掉」。

**改法**（后端接口零改动，只动前端与展示）：

- `static/js/app.js`
  - 新增 `newUid()` / `getUid()`：首次进来自动生成 **16 位随机 hex** 编号，存 `localStorage.recite_uid`，
    之后每次答题/拉题/看进度都用它当 `name` 参数 —— **页面不再问名字、没有登录步骤**。
  - ⚠️ **不用 `crypto.randomUUID()`**：它只在安全上下文（https / localhost）可用，
    而本项目是 `http://192.168.1.100:8090`，会直接 `undefined` → 改用 `crypto.getRandomValues` 自己拼 hex。
  - 16 位而不是 36 位 UUID：后端 `app.py` 对 `name` 做了 `[:20]` 截断，16 位正好不被截
    （36 位也能用——前缀截断是稳定的——但没必要贴着上限）。
  - 删掉 `setWho/askName/saveName` 与顶栏 🙋 换名按钮、`#whoName`；
    老师统计表里列名从「名字」改成「**编号**」，只显示前 8 位 + `title` 带全量。
- `templates/index.html`：删掉 `#view-name` 整块与顶栏名字位；资源版本戳 `?v=20261006a → 20261017a`（CSS/JS 都换）。
- `app.py`：只改文件头注释（进度按匿名编号记）；**接口逻辑一行没动**（`/api/cards`、`/api/answer`、
  `/api/progress`、`/api/stats` 照旧按 `name` 键存取，现在这个键是匿名编号）。
  → 存量进度不受影响：老学生用旧名字键继续记，新进来的用编号；老师页里两老三新都会列出。

**自伤记录**：第一次用一整段 `python3` 脚本做字符串手术（含大括号平衡删函数），把 `app.js` 删坏了
（`node --check` → `SyntaxError: Unexpected end of input`，15316 字节 vs 原 15030），而且
随后生成的 `.bak` **就是坏版本**（两个文件 md5 相同）。**恢复来源 = NAS 上已部署的未改动副本**
（`/vol1/1000/项目/背诵助手/static/js/app.js`，md5 `2a0cf98b9c2d35d53995db63a5ffafbf`）——
教训：**改坏后别信同目录里的 `.bak`，先比 md5；线上那份才是真基线。**
最终改法是「取回原文件 → `node --check` 确认 → `edit_file` 小步定点改 + 每步 check」。

**验证**：

| `python3 test_engine.py`（后端，未改动逻辑） | **51 / 0**（与改前一致） |
| `python3 ui_test.py`（真浏览器） | **31 / 0**（原 28 项 + 3 项新断言） |

`ui_test.py` 本轮新增/改写的断言：`#view-name` 不可见、`#nameInput` 不存在、进来**直接进练习**、
`localStorage.recite_uid` 自动生成且 16 位、**刷新后编号不变**、班级统计按「匿名编号」列出且**本机编号出现在统计里**。

## 五、坑（本轮踩到的）

1. **覆盖了同工作区的在制品**（见第一节）—— 动手前先看目录。
2. **测试里的「清理孤儿服务」必须放在启动服务之前**：UI 测试第一版把 `kill_orphans()` 写在
   `Popen` 之后，结果**把自己刚起的服务杀掉**，表现为"服务起不来"且服务端日志为空。
   已改成先清理、再启动。
3. 词条 id 与篇目 id 的差异：两版题库 id 不完全一致（如 `jihai_zashi` vs `jihaizashi`），
   合并时按 **id 优先、标题兜底**匹配，避免字词解释错挂到别的篇目。
